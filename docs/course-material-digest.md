## 4. CART/RF alignment notes

The course's CART/RF treatment (Shmueli-style, adapted by the instructor) maps directly onto scikit-learn with no translation gaps worth flagging as a mismatch:
- **Gini/entropy impurity** → `criterion='gini'`/`'entropy'` (classifiers) or MSE-based splitting (regressors) in `DecisionTreeClassifier`/`Regressor`.
- **Cost-complexity pruning / "best pruned tree within 1 SE"** → scikit-learn's `ccp_alpha` parameter implements the same cost-complexity pruning path; worth naming explicitly in the ML methodology doc since the course gives the "1 SE rule" by name.
- **mtry = sqrt(M) for classification, M/3 for regression** → this is *exactly* scikit-learn's default `max_features` for `RandomForestClassifier` (`'sqrt'`) and `RandomForestRegressor` (`1.0` historically, but the classic `M/3` recommendation the course cites matches the older/R-randomForest default, not sklearn's current default of using all features — **this is a real, worth-disclosing nuance**: if the project wants to mirror the course's RF definition precisely, set `max_features=1/3` explicitly for the regression model rather than relying on sklearn's current default, and say so in the model card).
- **OOB score** → `oob_score=True` on `RandomForestRegressor`, directly matching the course's worked OOB example; the ML evaluation report should report OOB R² alongside the held-out test R² since the course teaches OOB as a distinct validation concept from a normal train/validation split.
- **Bagging** → `BaggingRegressor`/the bootstrap step inside `RandomForestRegressor`; no special handling needed.
- ExtraTrees and HistGradientBoosting (both in the master spec's model list) are **not** covered in these slides at all — they're a legitimate "beyond the syllabus" addition the project makes for better performance, and should be labeled as such in the academic report (useful honesty for a viva question like "why these models beyond what was taught").
